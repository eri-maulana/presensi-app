# Kebijakan Privasi (Biometrik & Lokasi)

1. **Tujuan Pengumpulan Data**
   - Foto selfie dan data lokasi digunakan hanya untuk memverifikasi kehadiran.

2. **Penyimpanan**
   - Foto disimpan di server kampus selama maksimum 1 tahun.
   - Data dapat dihapus atas permintaan resmi pengguna.

3. **Akses Data**
   - Hanya admin dan dosen pengampu yang dapat mengakses foto presensi mahasiswa.

4. **Persetujuan**
   - Pengguna wajib menyetujui kebijakan ini saat pertama kali login atau mendaftar.

5. **Keamanan**
   - Password dienkripsi (bcrypt).
   - Foto & data GPS dikirim melalui koneksi HTTPS.

6. **Hak Pengguna**
   - Pengguna dapat meminta penghapusan data pribadinya melalui admin kampus.
