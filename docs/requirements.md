# Requirements - Aplikasi Presensi Kampus

## Tujuan
Membangun sistem presensi berbasis web untuk mahasiswa, dosen, dan admin dengan fitur selfie + GPS geofencing.

## Fitur Utama
- Autentikasi & Role: mahasiswa, dosen, admin.
- Presensi Masuk & Pulang (selfie + GPS).
- Validasi lokasi (geofence) menggunakan titik pusat kampus.
- Riwayat presensi & foto.
- Verifikasi manual oleh dosen.
- Laporan/Export (XLSX/PDF).
- Manajemen data (mahasiswa, dosen, mk, jadwal, lokasi kampus).
- Backup dan pengaturan sistem.

## Batasan & Asumsi
- Foto disimpan sementara dan diakses oleh dosen/admin untuk verifikasi.
- Pengguna menyetujui kebijakan privasi saat pendaftaran.
- Target awal: single-campus (nanti multi-campus).
